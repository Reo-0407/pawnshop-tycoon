# 전당포 타이쿤 — 설계 (2026-11-09)

5학년 친구들끼리 하는 웹 게임. 흥정·감정이 핵심, 닉네임 리더보드.

## 플랫폼
- 정적 HTML/CSS/JS (빌드 없음, ES 모듈) → GitHub Pages
- Supabase: 리더보드 표 1개 + 제출 함수(RPC) 1개 + 공개 뷰 1개
- 저장: localStorage(진행) + 하루 끝날 때 Supabase로 점수 제출
- 한국어, 폰 화면 지원

## 하루 흐름
1. 하루 손님 8명. 파는 손님 ~60%, 사는 손님 ~40%(진열대가 비면 파는 손님만).
2. **파는 손님**: 물건 + 부르는 값. 플레이어는 감정(시세 범위·진품 판정) 후 값을 제시.
   - 손님 최저가(비공개) 이상이면 성사. 아니면 손님이 중간값으로 되부름, 인내심 감소.
   - 너무 낮게 부르면(최저가의 60% 미만) 인내심 크게 감소. 인내심 0 → 떠남.
3. **사는 손님**: 진열품 하나를 골라 값 제시. 플레이어가 값을 부르고, 손님 최고가 이하면 성사.
   - 가품은 사는 손님이 항상 알아보고 거절(가품 판매 불가 → 순수 손해).
4. **고물상**: 언제든 진열품을 시세의 50%(가품 5%)에 처분.
5. 하루 끝 → 정산 → 업그레이드 상점 → 다음 날.

## 물건
- 40종, 4등급(잡동사니 / 생활용품 / 명품 / 보물). 각자 기본 시세·가품 확률.
- 매번 상태(상/중/하)에 따라 실제 시세 = 기본 × 0.6~1.4. 가품이면 실제 가치 ≈ 0.
- 감정: 돋보기 등급(1~3)에 따라 시세 범위 ±40% / ±25% / ±10%, 진품 판정 정확도 65% / 82% / 95%.

## 업그레이드
- 진열대 칸: 4 → 6 → 8 → 10 → 12
- 돋보기: 1 → 3
- 인테리어: 1 → 5 (높을수록 고등급 물건·부자 손님 확률↑, 사는 손님 최고가↑)

## 리더보드
- 총 재산 = 현금 + 진열품 실제 시세 합. 시작 현금 100,000원.
- 기기마다 랜덤 비밀키(localStorage). RPC가 비밀키로 본인 행만 갱신.
- 조작 방지: 날짜가 줄면 거부, 재산이 `이전×2.5 + 300,000×(날짜차)`를 넘으면 거부.
- 공개 뷰는 닉네임·재산·날짜만 노출.

## 그림
- 허깅페이스 FLUX.1-schnell로 미리 생성해 `assets/`에 커밋(물건 40 + 동물 손님 10 + 배경).
- 토큰은 저장소 밖에 두고 생성 스크립트에서만 사용, 한도 걸리면 다음 토큰으로 순환.
- 그림체: 밝고 귀여운 만화체, 손님은 동물 캐릭터.
